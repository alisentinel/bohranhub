# 🆘 بحران‌هاب | BohranHub

**مرکز منابع اضطراری و اطلاعات بحران**

یک وب‌سایت سبک، سریع و کاربردی برای دسترسی به اطلاعات حیاتی در شرایط بحران یا قطع اینترنت. این پروژه برای کار روی دستگاه‌های قدیمی و اتصالات ضعیف بهینه‌سازی شده است.

# برای افزودن سایت یا کتابچه با تلگرام من در تماس باشید.

## ⚠️ تذکرات مهم

- **عدم تایید محتوا**: ما محتوای معرفی‌شده در وب‌سایت‌ها را تأیید نمی‌کنیم.
- **امید به عدم نیاز**: امیدواریم هرگز نیازی به استفاده از این منابع نداشته باشید.
- **نشانگرها**:
  - پرچم = وب‌سایت‌های دولتی یا با پشتوانه دولت = پرچم رسمی همان کشور
  - 🌎 = وب‌سایت‌های بین‌المللی
- ما با هرگونه محدودیت و سانسور در بستر اینترنت بین‌الملل **مخالف** هستیم؛ این وبسایت هیچگونه تسهیل‌گری در جایگزینی سرویس‌های بین‌الملل نمی‌کند.

## ✨ ویژگی‌های کلیدی

- 🚀 **فوق‌العاده سبک**: HTML، CSS و JS به صورت inline و minified
- 📦 **فشرده‌سازی gzip**: کاهش 60-80% حجم صفحه
- ♿ **دسترس‌پذیر**: پشتیبانی کامل از screen reader با ARIA attributes
- 📱 **واکنش‌گرا**: طراحی ریسپانسیو برای همه دستگاه‌ها
- 🎯 **فیلتر پیشرفته**: جستجوی سریع با برچسب‌ها
- ⚡ **بدون وابستگی**: بدون نیاز به کتابخانه‌های خارجی
- 🌐 **کار آفلاین**: تمام منابع inline - بدون درخواست خارجی

## 🔧 نصب و راه‌اندازی

### پیش‌نیازها

- PHP 5.4+ یا بالاتر
- وب سرور (Apache، Nginx، یا PHP built-in server)

### مراحل نصب

1. **کلون کردن پروژه**
```bash
git clone https://github.com/AliSentinel/bohranhub.git
cd bohranhub
```

2. **کپی فایل نمونه داده**
```bash
cp data.json.example data.json
```

3. **ویرایش داده‌ها**
فایل `data.json` را با اطلاعات مورد نیاز خود ویرایش کنید.

4. **اجرای فایل**


## 📁 ساختار پروژه

```
bohranhub/
├── src/               # فایل‌های منبع
│   ├── index.html     # فایل اصلی (استاتیک)
│   ├── render.js      # رندر محتوا از data.json در مرورگر
│   ├── script.js      # فیلترینگ برچسب‌ها و چک‌لیست
│   ├── style.css      # استایل‌های CSS
│   ├── data.json      # داده‌های محتوا
│   ├── data.json.example  # نمونه فایل داده
│   ├── robots.txt
│   └── sitemap.xml
├── build.sh           # ساخت نسخه فشرده در dist/
├── dist/              # خروجی ساخت (گیت‌ایگنور، همین پوشه دیپلوی می‌شود)
├── .gitignore
└── README.md
```
سایت کاملاً استاتیک است و روی هر آبجکت‌استوریج اجرا می‌شود. برای اجرای محلی:

```bash
cd src && python3 -m http.server 8000
```

برای ساخت نسخه فشرده: `./build.sh` (خروجی در `dist/`).
